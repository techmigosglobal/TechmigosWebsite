## Role Overview

This is a backend engineering role focused on practical execution. You will design and support services that run in production cloud and VPS environments, with attention to reliability, performance, and long-term maintainability.

## What You Will Work On

- Build backend APIs and service logic for web and mobile products.
- Deploy and maintain workloads on cloud and VPS infrastructure.
- Improve logging, monitoring, and incident response readiness.
- Strengthen authentication, authorization, and data protection practices.
- Optimize performance bottlenecks in services and database access.

## Must-Have Qualifications

- Strong fundamentals in Node.js or Python backend development.
- Working knowledge of Linux environments and server operations.
- Understanding of API design, debugging, and error handling.
- Ability to write clean, testable code with clear reasoning.
- Ownership mindset and strong problem-solving discipline.

## Nice-to-Have Qualifications

- Familiarity with reverse proxies, load balancing, and TLS setup.
- Exposure to queues, workers, and event-driven processing patterns.
- Experience with cloud cost/performance optimization.

## Hiring Process

- Intro discussion about technical background and role expectations.
- Hands-on technical assessment based on realistic backend tasks.
- Review round focused on implementation quality and tradeoff thinking.

## Why Join TechMigos

- Work on production systems that demand practical engineering quality.
- Collaborate with teams that value accountability and craft.
- Grow through ownership of architecture and reliability outcomes.
