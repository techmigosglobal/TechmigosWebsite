## About the Role

We're looking for a Senior React Native Engineer to join our growing mobile practice. You'll build performant, user-friendly mobile applications that work seamlessly across iOS and Android platforms.

## Responsibilities

- Design and implement React Native applications from scratch
- Optimize app performance and ensure smooth animations
- Collaborate with backend engineers on API design
- Conduct code reviews and mentor junior team members
- Participate in architecture decisions and technical planning
- Work directly with clients to understand requirements and deliver solutions

## Requirements

- 4+ years of mobile development experience
- Expert-level React Native knowledge
- Strong TypeScript/JavaScript skills
- Experience with native iOS and Android development (Swift, Kotlin)
- Familiarity with mobile CI/CD pipelines
- Understanding of mobile security best practices
- Excellent communication skills

## Nice to Have

- Experience with Flutter or other cross-platform frameworks
- Published apps on App Store and Google Play
- Background in gaming or graphics programming
- Experience with wearable or IoT integration
