## Role Overview

We are hiring a Senior React Native Engineer to build and maintain mobile products used in real-world business environments. You will partner with design, backend, and QA teams to ship reliable features that feel native and perform smoothly.

## What You Will Work On

- Build and improve React Native applications for iOS and Android.
- Implement mobile UI flows with strong accessibility and responsiveness.
- Integrate APIs, handle state management, and optimize data flow.
- Improve startup speed, runtime performance, and crash stability.
- Collaborate on release quality, testing strategy, and production fixes.

## Must-Have Qualifications

- 4+ years of mobile development experience, including React Native.
- Strong proficiency with TypeScript/JavaScript and React fundamentals.
- Experience with app architecture patterns and reusable component design.
- Practical understanding of native module constraints and platform differences.
- Comfortable with Git workflows, debugging, and production support.

## Nice-to-Have Qualifications

- Experience with Expo tooling and build pipelines.
- Familiarity with Firebase services, push notifications, and analytics.
- Experience with mobile performance profiling and crash monitoring tools.

## Hiring Process

- Intro call to understand your product and engineering background.
- Technical round with React Native architecture and implementation deep-dive.
- Final round focused on collaboration, ownership, and delivery quality.

## Why Join TechMigos

- Build products with visible user impact across multiple industries.
- Work in a high-trust, remote-first engineering culture.
- Grow into architecture and technical leadership responsibilities.
