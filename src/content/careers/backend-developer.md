## Role Overview

Build the server-side systems that support TechMigos products. You’ll work with frontend and mobile developers to turn product requirements into API contracts, data models, and integrations that are straightforward to maintain.

## Responsibilities

- Design, document, and implement APIs and data models for client-facing products and internal tools.
- Build authentication and permission checks and handle validation, errors, and retries at service boundaries.
- Write automated tests for critical workflows, review code, and diagnose failures from logs and metrics.
- Plan database changes and integrations with attention to existing data and clients.
- Help ship releases, document operational decisions, and support the team when production issues arise.

## Qualifications

- Practical experience building backend software in Node.js, TypeScript, Python, or a comparable stack.
- Familiarity with HTTP APIs, authentication, data modeling, and automated testing.
- Working knowledge of relational databases or a managed database such as Firestore.
- Ability to debug issues methodically and explain technical trade-offs to teammates.

## Helpful Experience

- Firebase Auth, Firestore, or Cloud Functions, or experience with comparable managed services.
- CI/CD, monitoring, database migrations, or integrating third-party APIs.
