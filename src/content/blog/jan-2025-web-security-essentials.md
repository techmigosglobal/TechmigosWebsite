## Common Mistake

Teams often focus on feature speed and postpone security controls until after launch.

## Security Baseline

- Validate every input.
- Use httpOnly cookies for sessions.
- Rotate secrets and avoid defaults.

## Team Habit

Run a lightweight security review for every release candidate.
